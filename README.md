# 雾灯旅团 v0.1 playable slice

这是《雾灯旅团》的首次可玩工程，覆盖 M0 内容/存档底座、M1 五人行动条战斗，以及 M2 招募—编队—基础培养—胜利掉落闭环。统一内容注册表现有 42 位 SSR、48 位 SR 与 72 位 R，共 162 位伙伴角色；首版战斗按角色模板运行，低稀有角色复用已验证的同职能技能实现，逐 SSR 专属完整机制和 M3 全量内容仍待接入。

招募采用“雾海契约”演出：结果先保存，卡片从裂缝飞出后保持背面，点击才揭晓。完整演出先聚光显色、展开多层裂隙，再由同一批卡飞入最终格位，不再切换大小卡阵。点击空白处或快速按钮让 R/SR 从原格位抬起、放大、翻面、落回；SSR 卡背金光与持续颤动，点击进入专属空间，从裂隙深处飞近并悬停翻面。SR 使用紫光与较轻震动。已取消屏幕与舞台震动；SSR 改为小幅颤动，金色光源大范围散出卡阵，并有沿卡缘环流的金色电弧；待揭晓时舞台染上暗金环境光。裂隙与 SSR 演出共用屏幕底部中央的快进按钮（空格）。SSR 独立演出约 4.9 秒：从深处飞近、卡背延长悬停，两侧提前显现精简的定位、站位和能力关键词，随后翻面揭晓。快速翻开、收下契约、SSR 返回按钮统一放在屏幕底部中央。卡面为绰号预留固定行，图标对齐、底部文字不再被挤出。设置中的减少动态可关闭强运动。R 青灰、SR 紫色、SSR 金色同步用于卡面、图鉴、招募记录、配队和角色仓库。刷新可继续揭晓，不会再次扣券。新档用系统安全随机源生成非固定种子，后续随机状态随存档保存。

免费招募：北京时间每个整点刷新常驻单招一次；每天 23:00 刷新常驻十连一次、主题单招一次。三个额度各自独立、不累积，不扣招募券，计入原池保底与全池累计次数。主题仍在序章完成后开放。

角色图鉴由同一注册表驱动，提供总收藏及分稀有度进度、姓名搜索、稀有度/职能/拥有状态/来源分组筛选、未获得角色技能预览、已拥有培养状态与 NEW 标记。发现记录独立保存，回收重复卡不会抹除收藏。

## 下载与启动

这是面向 Windows 桌面端的本地可玩切片。打开本仓库的 GitHub 页面，选择 **Code → Download ZIP**，下载后解压到本机可写目录。请先安装 Node.js 20 或更高版本。

不要只双击 `public/index.html` 或其他 HTML 文件：游戏需要本地服务提供存档、测试接口和模块加载。

Windows 下优先直接双击项目根目录中的 `【双击启动】雾灯旅团.cmd`。脚本会避免重复启动服务，并自动打开游戏页面。

也可以使用命令行启动：

需要 Node.js 20 或更高版本。在本目录执行：

```powershell
npm run dev
```

然后打开 <http://localhost:4173>。

关闭网页或停止本地服务后不会继续战斗，也不会补算离线收益；需要推进战斗时请保持网页和本地服务运行。

## 验证

```powershell
npm test
npm run validate
```

测试命令会运行本地 Node.js 测试套件和内容校验，不会替代实际试玩。当前验收范围是 Windows 桌面端的 localhost 可玩切片；本项目没有在线版、安装包或移动端支持。

## 存档与测试档

首次打开后，在“选择存档”中选择一个空位即可建立存档并开始序章。正式存档共有三个位置，分别保存角色、剧情、资源、免费额度和揭晓进度；存档 1 在存在旧版本地进度时负责迁移旧进度。剧情内也能打开存档选择。

当前三档数据写入 `runtime/save.slots.json`，原 `runtime/save.json` 保留为首次迁移的原件，不再用作当前写入文件。设置页导出/导入仅针对当前存档，导入会替换当前旅程；备份全部位置请保存 `runtime/save.slots.json`。使用 `MIST_SAVE_PATH` 时，三档文件为同目录下对应的 `.slots.json` 文件。网页关闭后服务器不会推进战斗，也不会补算离线收益。

“选择存档”下方另有独立测试存档，不占三个正式档位。测试档用于验证资源、角色领取和现有内容，不代表正式游玩进度；默认招募券 999、金币 99,999,999、契约碎片 9,999，并开放现有内容。测试工作台可直接设置六种资源总量、领取指定角色 1～1000 张；首次解锁后的额外张数保留为重复凭证，不计招募与保底。数据写入 `runtime/save.test.json`，与 `save.slots.json` 分开；工作台接口仅允许测试档调用。不要把 `runtime/` 中的正式存档、测试存档或运行日志上传到 GitHub。

## 当前交互更新

- 战斗加入角色前冲、攻击轨迹、命中闪光与受击颤动；治疗、护盾、攻击增益分别使用绿色、蓝色、金色光效与实际数值飘字。动画跟随 1～3 倍速，系统减少动态时省略前冲、飞行与颤动。
- 行动基础间隔为 660 毫秒，2 倍速 330 毫秒、3 倍速 220 毫秒（另加本地请求开销）。第一关敌人血量调整为原来的 55%，后两场序章为 70%；旧驿道血量不变。治疗在健康时普攻、保留大招，支援避免重复刷新已有攻击增益，护盾充足时保护角色改为普攻；敌方首领主动护盾仅保护自己，大招仍可全队加盾。新血量用于新开战斗，已有战斗保留原属性。
- 配队有改动时明确提示尚未保存；请点击“保存编队（有变更）”，之后新开战斗才使用新队伍。
- 序章前加入主角背景页，八段 86 句剧情改成明确的白话文，任务和操作重点加粗；角色介绍保留固定高度，剧情框随发言人的品质着色。
- 主角作为独立条目置顶图鉴，不计入 R/SR/SSR 收藏；以 SR 数值起步，独立成长记录不设内容等级上限，序章首次关键胜利累计提供 35% 生命/攻击/防御成长。当前是成长档案与站位，暂不作为第六名战斗单位出手。
- 主角与五名伙伴在九宫格自由拖动、互换；提起放大 6%。前排生命/防御 +15%，中排攻击 +10%，后排治疗/护盾 +15%；保存后作用于下一场战斗，进行中的战斗使用原快照。
- 空格推进背景和对话；招募时用于跳过演出、翻开普通卡、返回卡阵和收下已揭晓结果。Tab/Enter 可操作具体按钮，输入框不拦截空格，长按不会连跳剧情。招募不再提供稍后查看。

- SSR 推荐站位独立于职业模板：近战输出可在前排，远程输出偏中排，治疗和支援偏后排。石敢当保留重装近战单体输出并推荐前排，迟音推荐后排；不会强制站位或改变技能模板。
- 当前以桌面 localhost 为验收范围，后续暂不投入移动端适配。
