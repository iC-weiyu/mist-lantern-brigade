# 雾灯旅团 v0.2.1 playable slice

这是《雾灯旅团》的首次可玩工程，覆盖 M0 内容/存档底座、M1 五人行动条战斗，以及 M2 招募—编队—基础培养—胜利掉落闭环。统一内容注册表现有 42 位 SSR、48 位 SR 与 72 位 R，共 162 位伙伴角色；首版战斗按角色模板运行，低稀有角色复用已验证的同职能技能实现，逐 SSR 专属完整机制和 M3 全量内容仍待接入。

招募采用“雾海契约”演出：结果先保存，卡片从裂缝飞出后保持背面，点击才揭晓。完整演出先聚光显色、展开多层裂隙，再由同一批卡飞入最终格位，不再切换大小卡阵。点击空白处或快速按钮让 R/SR 从原格位抬起、放大、翻面、落回；SSR 卡背金光与持续颤动，点击进入专属空间，从裂隙深处飞近并悬停翻面。SR 使用紫光与较轻震动。已取消屏幕与舞台震动；SSR 改为小幅颤动，金色光源大范围散出卡阵，并有沿卡缘环流的金色电弧；待揭晓时舞台染上暗金环境光。裂隙与 SSR 演出共用屏幕底部中央的快进按钮（空格）。SSR 独立演出约 4.9 秒：从深处飞近、卡背延长悬停，两侧提前显现精简的定位、站位和能力关键词，随后翻面揭晓。快速翻开、收下契约、SSR 返回按钮统一放在屏幕底部中央。卡面为绰号预留固定行，图标对齐、底部文字不再被挤出。设置中的减少动态可关闭强运动。R 青灰、SR 紫色、SSR 金色同步用于卡面、图鉴、招募记录、配队和角色仓库。刷新可继续揭晓，不会再次扣券。新档用系统安全随机源生成非固定种子，后续随机状态随存档保存。

免费招募：北京时间每个整点刷新常驻单招一次；每天 23:00 刷新常驻十连一次、主题单招一次。三个额度各自独立、不累积，不扣招募券，计入原池保底与全池累计次数。主题仍在序章完成后开放。

角色图鉴由同一注册表驱动，提供总收藏及分稀有度进度、姓名搜索、稀有度/职能/拥有状态/来源分组筛选、未获得角色技能预览、已拥有培养状态与 NEW 标记。发现记录独立保存，回收重复卡不会抹除收藏。

## 下载与启动

这是面向 Windows 桌面端的本地可玩切片，三步就能进游戏：

1. **装 Node.js**：到 <https://nodejs.org/zh-cn/download> 下载 LTS 版并安装（需要 20 或更高版本，安装时保持默认选项即可）。
2. **下载本项目**：在本仓库页面点 **Code → Download ZIP**，把 ZIP **完整解压**到一个可写目录（不要在压缩包里直接双击运行）。
3. **双击根目录的 `【双击启动】雾灯旅团.cmd`**：脚本会启动本地服务并自动打开浏览器进入初始界面；再次双击只会打开页面，不会重复启动服务。

不要只双击 `public/index.html` 或其他 HTML 文件：游戏需要本地服务提供存档、测试接口和模块加载。也不要只复制 `public/` 目录，`server.mjs` 与 `src/` 同样必需。

常见问题：

- **双击没反应 / 提示被系统拦下**：从网上下载的文件会带“来自其他计算机”的锁定标记。启动器会自动尝试解除；若仍被拦，右键 `【双击启动】雾灯旅团.cmd` → 属性 → 勾选“解除锁定”，或直接点“仍要运行”。
- **提示没有找到 Node.js 或版本过低**：按窗口里的提示装好 Node.js 20+ 后重新双击即可。
- **启动窗口说服务没起来**：窗口里会显示 `runtime/server.stderr.log` 的最后几行；把内容发到 issue 即可。
- **端口 4173 被占用**：脚本检测到已有服务在跑时会直接打开页面；若是别的程序占用，请先关掉它。

也可以命令行启动（同样需要 Node.js 20+）：

```powershell
npm run dev
```

然后打开 <http://localhost:4173>。

给朋友的最快方式：把解压后的整个文件夹（或 GitHub 的 ZIP）直接发给他，他解压后双击 `【双击启动】雾灯旅团.cmd` 就能玩；下载本仓库不需要 GitHub 账号。存档各自保存在自己电脑的 `runtime/` 目录里，互不影响，也不会互相覆盖。

关闭网页或停止本地服务后不会继续战斗，也不会补算离线收益；需要推进战斗时请保持网页和本地服务运行。

## 初始界面

打开或刷新页面会先进入初始界面：全屏使用雨夜会馆实景图 `public/assets/title-bg.jpg`，叠加斜向雨落动效与左侧柔和遮罩，标题、按键与文字改为暖白色半透明，保证可读的同时不遮挡画面右侧的会馆与背影。标语为“夜雨千山，微光烁烁，不问来路，只将那些离散的人，缓缓渡回此间”。

- **选择存档**：在初始界面内展开三个正式档位与独立测试存档的列表，选定后进入会馆；该档位若有进行中的战斗，会直接回到战斗页。存档名称与进度只在面板内显示，标题画面本身不出现存档信息。
- **新建存档**：自动占用第一个空档位，弹窗可填写旅团手记名称（留空则按档位默认命名），确认后从序章第一段开始。三个档位占满时会先展开存档列表，提示删除不需要的存档。
- **退出游戏**：先二次确认；脚本打开的标签页会被直接关闭，浏览器阻止关闭时改为显示“已退出”告别画面并淡出声音。
- **右上角喇叭**：只有一个图标按钮，用于开关初始界面环境音（见下）。

侧边栏不再保留“选择存档”入口。会馆内在设置页可点击“返回初始界面”。

## 声音

初始界面的环境音由 Web Audio 实时合成，不加载外部文件；会馆背景乐播放仓库内的音频文件。受浏览器自动播放策略限制，首次点击或按键后才会出声。设置页的“声音”卡片集中管理全部开关与音量。

- **初始界面环境音**：低通雨幕、雾状嘶声、两处屋檐风层与随机雨点，另外每隔约半分钟有一次远处的闷雷——慢起音、长衰减、只保留 100～200Hz 的低频滚动，并且伴随一次很轻的画面提亮；不会出现突发或尖锐的爆音。右上角喇叭可随时关闭。
- **会馆背景音乐**：播放 `public/assets/hall-bgm.mp3`（《五音疗愈养心古琴》· 秋琴紫若，MPEG1 128kbps 48kHz，约 3 分 34 秒）。一曲播完后**等待 30 秒**再从开头循环；离开会馆或回到初始界面时淡出并暂停，再次进入从中断处继续；标签页切到后台时暂停、回到前台接着放。设置页可调整音量（默认 55%）并显示当前是否已载入文件与曲目时长。
- **换曲目**：替换 `public/assets/hall-bgm.mp3` 即可；也支持 `.m4a`／`.ogg`／`.wav`／`.flac`（按 `mp3 → m4a → ogg → wav → flac` 顺序探测第一个存在的），不需要改代码。
- 该音频为第三方曲目（《五音疗愈养心古琴》· 秋琴紫若），当前随工程一起保存，仅供作者与朋友私下游玩；若要公开发布、商用或以其他方式再分发，请先取得授权或替换成有授权的音乐。

## 序章取名

新建存档后第一次进入会馆，序章开场会先出现一页「风雨一途，敢问足下高名？」：

- 填 1～12 个字并确认，此后同伴都会这样称呼你：编队九宫格里的站位、战斗阵容里的主角占位、剧情中由「你」发言的对白标签、以及主角档案的标题与头像，全部改用这个名字。
- 每个存档只问一次；剧情的跳过、回看与重新进入都不会再出现。想不起来也没关系：留空确认就沿用默认名「浪人」。改名入口在设置页的「主角 · 名字」卡片里，随时可改。
- 名字随存档保存在 `profile.name`，导出/导入存档会一起带走；空格键不会越过这一步，输入框里按回车即可确认。

## 图标与快捷方式

- **网页图标**：`public/favicon.ico`（16/32/48/64 用传统 DIB、128/256 用 PNG 内嵌，浏览器与资源管理器都能正确解码）、`public/assets/icon-192.png`、`icon-512.png`，已在 `index.html` 挂好；浏览器标签页与「添加到主屏」都会用它。源图是 `public/assets/icon-source.jpg`，改图后跑一次 `powershell -ExecutionPolicy Bypass -File tools\make-icons.ps1` 即可重新生成（同一源图可复现同样结果）。
- **桌面快捷方式**：启动器首次运行会在桌面创建带游戏图标的「雾灯旅团」快捷方式，双击即进；不想要可以直接删掉，或给 `tools/launch-game.ps1` 加 `-NoShortcut` 参数跳过。

## 存档与测试档

首次打开后，在初始界面点“新建存档”即可建立存档并开始序章。正式存档共有三个位置，分别保存角色、剧情、资源、免费额度和揭晓进度；存档 1 在存在旧版本地进度时负责迁移旧进度。剧情与会馆内均可通过“返回初始界面”回到标题画面，再重新选择存档。测试存档同样列在初始界面的存档面板中。

当前三档数据写入 `runtime/save.slots.json`，原 `runtime/save.json` 保留为首次迁移的原件，不再用作当前写入文件。设置页导出/导入仅针对当前存档，导入会替换当前旅程；备份全部位置请保存 `runtime/save.slots.json`。使用 `MIST_SAVE_PATH` 时，三档文件为同目录下对应的 `.slots.json` 文件。网页关闭后服务器不会推进战斗，也不会补算离线收益。

初始界面的存档面板中另有独立测试存档，不占三个正式档位。测试档用于验证资源、角色领取和现有内容，不代表正式游玩进度；默认招募券 999、金币 99,999,999、契约碎片 9,999，并开放现有内容。测试工作台可直接设置六种资源总量、领取指定角色 1～1000 张；首次解锁后的额外张数保留为重复凭证，不计招募与保底。数据写入 `runtime/save.test.json`，与 `save.slots.json` 分开；工作台接口仅允许测试档调用。不要把 `runtime/` 中的正式存档、测试存档或运行日志上传到 GitHub。
