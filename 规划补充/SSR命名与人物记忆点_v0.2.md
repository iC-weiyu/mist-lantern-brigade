# 《雾灯旅团》SSR 命名与人物记忆点 v0.2

用途：为 42 位 SSR 提供卡面显示名、命名口径与一句记忆点，供 `src/content.mjs` 按稳定 ID 应用。
本表是重建稿：新显示名与记忆点均为按《角色设计_v0.1.md》既有设定补写的默认值，称号与旧名必须与原始设定一致。42 人中 38 人换显示名，4 人保留旧名。

## 命名口径

- 显示名统一为两字，取自外观、道具或行为特征，不用称号、不做人名化。
- 旧名继续作为别名保留在角色资料与稳定 ID 说明中；技能文案内的旧名会一并替换为显示名。
- 记忆点写“值得被记住的一件事”，不描述数值与技能，便于图鉴与卡面共用。
- 同名检查以显示名为准，全表不允许重复。
